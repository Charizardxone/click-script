# 需求与使用范围

Click Script 面向需要重复执行桌面操作、验证交互流程或复现固定演示步骤的用户。用户通过桌面界面配置目标图片和顺序，即可创建、保存和运行一项点击任务。项目用于用户有权操作的软件与测试环境。

## 使用场景

- **重复操作**。依次点击本地窗口里外观相对固定的按钮，并按需要运行多轮。
- **交互测试**。为每个步骤指定搜索区域、阈值和等待时间，在运行日志中查看执行到哪一步，以及目标是否识别成功。
- **流程复用**。把任务配置和目标图保存到同一个目录，之后重新打开继续编辑或运行。

## 功能范围

| 功能 | 行为 |
| --- | --- |
| 目标图片 | 导入本地图片或从桌面框选截图。一个目标可被多个步骤引用，识别测试会显示最高匹配分数、位置和耗时。 |
| 任务编辑 | 添加、删除、拖拽排序或禁用步骤。每步可设置全屏或矩形搜索区域、匹配阈值、超时、轮询间隔、点击前后等待和失败处理。 |
| 任务运行 | 按顺序执行已启用步骤，支持有限次数循环、无限循环、启动倒计时和轮间等待。最后一轮结束后直接完成任务。 |
| 执行反馈 | 界面显示当前轮次、步骤状态和执行日志。步骤识别失败时可停止任务、跳过该步骤或重试。 |
| 运行控制 | 使用界面暂停、继续或停止。全局热键可用时，可按 `Ctrl+Alt+F12` 请求紧急停止。 |
| 本地保存 | 支持新建、打开、保存和另存为。任务配置和目标图片保存在用户选定的目录。 |

## 验收用例

以下用例用于检查常用流程。

1. **保存与重开**。通过导入和截图各创建一个目标，添加为步骤并交换顺序。保存、关闭并重新打开任务，检查图片、顺序和参数能否恢复。
2. **定位与复核**。运行一个配置了点击前等待的步骤。在等待期间移动或隐藏目标，检查复核是否使用更新的位置，或在目标消失时进入失败处理。
3. **超时与重试**。让目标保持不可见，分别检查停止、跳过和重试的行为。在轮询或重试等待中请求停止，检查任务能否退出。
4. **循环与运行控制**。运行两轮任务，检查轮间等待只出现在第一轮结束后。运行中暂停并恢复，再通过全局热键检查停止行为。
5. **坐标与缩放**。在实际使用的 DPI 和显示器布局中，用位置已知的按钮对照截图选区、识别坐标和点击位置。混合 DPI 和带负坐标的布局需要分别验证。

## 适用边界

当前任务使用顺序步骤。识别以可见画面和接近模板的尺寸为前提。每个步骤配置的超时用于限制一次查找，任务总时长还受点击等待、失败策略和循环设置影响。涉及页面切换或业务结果的测试，需要另外确认点击后的画面与状态。
