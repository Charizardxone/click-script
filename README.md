# Click Script

Windows 图像识别点击任务编辑器。用户可以导入或截图创建目标图片，把目标编排成有顺序的步骤，并通过 OpenCV 在桌面中识别目标后执行自然鼠标点击。

## 当前功能

- PySide6 桌面操作界面
- 导入目标图片或全屏框选截图
- 图片识别测试与置信度展示
- 点击步骤添加、删除、拖拽排序和启用/禁用
- 每步配置阈值、超时、等待、重试和搜索区域
- 任务循环、启动倒计时、暂停、继续和停止
- 可配置的每轮之间随机等待
- 三次贝塞尔平滑鼠标轨迹
- 目标安全区域内的截断二维正态点击分布
- 偏向最小值、偶尔接近最大值的混合等待分布
- 等待期间可配置的全屏平滑鼠标游移
- 点击前重新识别目标，避免使用等待前的旧坐标
- Win32 `SendInput` 鼠标按下和释放
- `Ctrl+Alt+F12` 全局紧急停止
- JSON 与图片目录形式的本地任务项目

本项目用于用户有权操作的软件自动化和桌面交互测试，不用于绕过验证码、反作弊或第三方安全机制。

## 环境

- Windows 10 / Windows 11
- uv
- Python 3.12（由 uv 管理）

## 安装

仓库已经包含 `uv.lock`。首次使用执行：

```powershell
uv sync
```

如果系统默认 uv 缓存目录不可用，可以把缓存放在项目目录：

```powershell
uv --cache-dir .uv-cache sync
```

## 启动

```powershell
uv run click-script
```

或：

```powershell
uv run python -m click_script
```

## 使用流程

1. 点击“导入”选择已有按钮图片，或点击“截图”在桌面框选目标。
2. 在左侧选择目标，点击“添加为步骤”。
3. 拖动中间列表调整顺序。
4. 在右侧调整阈值、超时、等待和失败处理。
5. 如有需要，为步骤框选搜索区域以降低误识别和提高速度。
6. 保存任务目录。
7. 点击“开始”。启动后可暂停、继续或停止。

“轮间”最小值和最大值只在当前轮完成且还需要执行下一轮时生效。最后一轮结束后不会额外等待；无限循环则会在每轮结束后等待。轮间等待沿用自然点击设置中的混合分布和鼠标游移配置。

运行期间可以按 `Ctrl+Alt+F12` 请求紧急停止。

## 等待时间与鼠标游移

点击前、点击后的等待不采用均匀随机。默认情况下：

- 90% 进入短等待模式，结果明显偏向配置的最小等待时间。
- 10% 进入长等待模式，结果明显偏向配置的最大等待时间。
- “等待偏向强度”越大，结果越靠近对应端点，默认值为 `6.0`。
- 等待超过 350 ms 时，默认有 40% 概率产生最多 2 次全屏随机方向的平滑游移。
- 每次游移会随机选择虚拟桌面中的安全位置；等待预算不足时沿该方向移动一段。
- 移动速度默认在基础速度上下 25% 范围内随机变化。

可在顶部“自然点击设置”中调整长等待概率、偏向强度、速度随机幅度、游移概率、屏幕边缘留白和最多游移次数。点击前等待完成后，程序会重新识别目标，然后从当前鼠标位置沿平滑轨迹移动到目标；只有目标仍然存在时才会点击。

## 任务目录

保存后目录结构如下：

```text

├─ task.json
└─ images/
   ├─ <target-id>.png
   └─ ...
```

## 已知限制

- 当前使用单尺度模板匹配，目标显示尺寸需要与模板大体一致。
- 目标处于遮挡或最小化窗口中时通常无法识别。
- 高 DPI 和混合 DPI 多显示器已做物理像素处理，但仍建议在实际显示器布局中校准截图选区。
- 当前没有点击后图片消失/出现验证功能。
- 全局热键受系统权限级别影响；操作管理员窗口时，本程序可能也需要以相同权限运行。
