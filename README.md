# Click Script

**Windows 桌面自动化工具 · 个人项目**

Click Script 用于重复的桌面操作与交互测试。用户可以截图或导入目标图片，把操作编排成一组步骤。运行时，程序在屏幕中查找目标，再按识别到的位置依次点击。目标图片、步骤和运行参数可以保存，方便下次继续使用。

## 功能

| 功能 | 操作 |
| --- | --- |
| 目标管理 | 导入图片或框选屏幕截图，通过「测试识别」查看匹配分数、位置和耗时。 |
| 步骤编排 | 添加、排序或禁用步骤，分别设置搜索区域、匹配阈值、超时、点击前后等待和失败处理。 |
| 运行控制 | 设置倒计时、循环次数和轮间等待。运行中可查看进度和日志，暂停、继续或停止任务。 |
| 任务保存 | 将配置和目标图片保存到同一目录，通过 `task.json` 重新打开任务。 |

## 实现要点

- **点击前复核**。使用 mss 截取虚拟桌面或指定矩形区域，用 OpenCV 单尺度模板匹配定位目标。点击前的等待结束后重新截图识别，目标仍满足阈值时才使用新的位置执行点击。
- **后台执行与取消**。PySide6 的 `QThread` 承载任务循环，Qt 信号将进度和步骤结果回传界面。轮询、等待和鼠标移动在检查点处理暂停和取消。鼠标按下后，程序通过 `finally` 尝试释放按键。
- **鼠标轨迹与输入**。在目标内部采样点击点，用带缓动的三次贝塞尔曲线生成移动轨迹，通过 Win32 `SetCursorPos` 移动鼠标，使用 `SendInput` 发送按下和释放事件。

## 快速开始

需要 Windows 10 或 Windows 11，以及 uv。项目配置使用 Python 3.12，依赖版本由 `uv.lock` 锁定。在仓库根目录运行以下命令。

```powershell
uv sync
uv run click-script
```

1. 打开一个可操作的本地窗口。点击「截图」框选按钮，或用「导入」添加目标图片。
2. 在左侧选择目标，点击「测试识别」查看当前屏幕上的匹配结果，再点击「添加为步骤」。
3. 在中间列表调整步骤顺序，在右侧配置阈值、超时和搜索区域。画面中有相似按钮时，可通过「框选搜索区域」缩小查找范围。
4. 点击「保存」选择任务目录，再点击「开始」。运行中可以用界面上的「停止」或 `Ctrl+Alt+F12` 请求停止任务。

迁移任务时，把 `task.json` 和同目录的 `images/` 一起复制，再打开新目录中的 `task.json`。

## 使用边界

- 识别依赖屏幕上可见的像素。目标被遮挡、窗口最小化或相对模板明显缩放时，可能无法匹配。
- 每次点击后按配置等待。页面是否切换或目标是否消失需由用户确认。
- 在高 DPI 或混合缩放的多显示器环境中，先用「测试识别」和单步任务确认截图与点击坐标。全局热键和鼠标输入可能受 Windows 权限影响。
